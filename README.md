# Koperasi Desa Merah Putih Kombo  
Dokumentasi ekosistem usaha terpadu Koperasi Desa Merah Putih Kombo

Portal ini merupakan dokumentasi terbuka ekosistem usaha terpadu Koperasi Desa Merah Putih Kombo yang mengintegrasikan pertanian, peternakan, perikanan, pakan mandiri, pupuk organik, logistik, kesehatan, dan layanan ekonomi desa dalam satu sistem berkelanjutan.

## 🎨 Panduan Warna (60–30–10)
- **60% Putih (#FFFFFF)** – background utama, ruang baca
- **30% Merah Darah (#8A0303)** – heading, garis, ikon gerai
- **10% Abu-abu (#D9D9D9)** – border, label, elemen sekunder
